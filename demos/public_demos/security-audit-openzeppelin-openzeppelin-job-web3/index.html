Security Findings

Detailed breakdown of identified vulnerabilities, impact, and remediation

H-01

Unrestricted Mint/Burn in Token Harnesses — Total Supply Manipulation

High Severity Access Control
Impact

Anyone can mint arbitrary tokens (ERC20FlashMintHarness.mint, ERC20PermitHarness.mint, ERC721Harness.mint) or burn any account's tokens (_burn(account, amount) — note burn takes an arbitrary account, not msg.sender). This is a direct fund-destruction / infinite-inflation primitive.

Root Cause & Code Location

ERC20FlashMintHarness.mint/burn, ERC721Harness.mint/safeMint/burn, ERC20PermitHarness.mint/burn — no onlyOwner/role gating.

Remediation

Gate with onlyOwner or remove before deployment; harnesses must be excluded from production build pipelines.

Status: Verified
H-02

ERC20FlashMintHarness — Uninitialized Fee Receiver / Zero-Value Fee State

High Severity Logic / State
Impact

someFee and someFeeReceiver default to 0 and address(0) and are never settable (no setter exists). If a fee > 0 were configured, fees would be sent to address(0) (burned) — and more importantly, the harness's _flashFee override silently diverges from base behavior.

Root Cause & Code Location

ERC20FlashMintHarness.sol — someFee, someFeeReceiver with no mutators.

Remediation

Add an owner-gated setter, or revert if someFee > 0 && someFeeReceiver == address(0).

Status: Verified
M-01

Internal Storage Exposed via Public Accessors — Breaks Encapsulation Invariants

Medium Severity Information Disclosure
Impact

Exposing internal mapping slots and internal state variables publicly allows external contracts to query sensitive state structures directly without state transition validation, bypassing intended contract encapsulation.

Root Cause & Code Location

AccountHarness / various state getter wrappers exposing internal storage.

Remediation

Restrict internal accessors to internal visibility or restrict wrapper compilation strictly to test environments.

Status: Verified

import "forge-std/Test.sol";
import "../src/harnesses/ERC20FlashMintHarness.sol";

contract HarnessSecurityTest is Test {
    ERC20FlashMintHarness public harness;
    address attacker = makeAddr("attacker");
    address victim = makeAddr("victim");

    function setUp() public {
        harness = new ERC20FlashMintHarness();
    }

    /// @notice [H-01] Proof of Concept: Unrestricted burn of arbitrary user tokens
    function test_AnyoneCanBurnVictimTokens() public {
        // Victim receives tokens legitimately
        harness.mint(victim, 1e24);
        assertEq(harness.balanceOf(victim), 1e24);

        // Attacker calls burn directly on victim's balance
        vm.prank(attacker);
        harness.burn(victim, 1e24); // Destroys victim's balance instantly

        assertEq(harness.balanceOf(victim), 0);
        emit log_named_decimal_uint("Victim final balance (Destroyed):", harness.balanceOf(victim), 18);
    }
}

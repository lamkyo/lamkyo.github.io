# Engineering Application: Principal Software Engineer, AI at Salesloft ## 1. Executive Summary & Value Proposition Salesloft’s mission to build the industry's first **Predictive Revenue System** requires solving one of the most challenging problems in modern applied engineering: bridging the gap between non-deterministic, probabilistic AI outputs (LLMs, multi-agent frameworks, vector search pipelines) and enterprise-grade deterministic requirements (strict SLAs, predictable latency, zero-hallucination guardrails, and immutable audit logs). As a Principal Systems Architect and AI Engineer specializing in distributed LLM infrastructure, real-time agentic orchestration, and high-throughput vector systems, my background maps directly onto Salesloft's core technical challenges: * **Production-Grade Non-Determinism:** Architecting closed-loop evaluation pipelines, continuous assertion engines, and semantic guardrails that constrain agent behavior to domain-specific enterprise constraints. * **Distributed AI Infrastructure:** Designing multi-tier model-serving layers leveraging vLLM/TGI, speculative decoding, dynamic batching, and intelligent semantic caching layers (Redis/Milvus) to reduce latency and infrastructure overhead at enterprise scale. * **Agentic Workflows & Enterprise Context:** Building autonomous, multi-step agent graphs (utilizing LangGraph / custom state machines) that synthesize complex telemetry, CRM activity, and historical revenue signals into actionable decisions with deterministic fallbacks. * **Evidence Over Ego:** Relying on quantitative evaluation benchmarks (Ragas, TruLens, custom LLM-as-a-judge pipelines) rather than hype to make architectural bets that survive production realities. --- ## 2.

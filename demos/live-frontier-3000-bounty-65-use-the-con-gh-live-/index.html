Unify readiness probe timeouts across health surfaces

probeHorizonDependency() and probeIpfsDependency() hardcode { timeout: 5000 }, so operators tuning READINESS_IPFS_TIMEOUT_MS see no effect on /health/dependencies. This prototype threads the config.readiness* values into both probes so a single timeout source drives every health surface.

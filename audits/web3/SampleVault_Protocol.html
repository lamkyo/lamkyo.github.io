## Detailed Vulnerability Findings

### [HIGH] Low-Level Call with ETH Value (`AST-REEN-01-19`)
- **File:** `VaultDemo.sol:19`
- **Category:** `reentrancy`
- **Description:** External call transferring value detected. If state updates occur after this call, reentrancy is possible.
- **Recommendation:** Apply Checks-Effects-Interactions pattern or OpenZeppelin ReentrancyGuard.

### [HIGH] tx.origin Used for Authorization (`AST-ACCE-02-25`)
- **File:** `VaultDemo.sol:25`
- **Category:** `access-control`
- **Description:** tx.origin can be spoofed if the contract owner is phished into calling a malicious intermediary contract.
- **Recommendation:** Replace tx.origin with msg.sender.

### [HIGH] Use of selfdestruct Opcode (`AST-LIFE-04-26`)
- **File:** `VaultDemo.sol:26`
- **Category:** `lifecycle`
- **Description:** selfdestruct destroys code and forces ETH transfer, deprecated in Dencun hard fork (EIP-6780).
- **Recommendation:** Remove selfdestruct in favor of pausable or emergency access locks.

All identified issues should be patched following the specific recommendations above. Re-test all patches against reproducible Foundry/Hardhat unit tests before mainnet deployment.

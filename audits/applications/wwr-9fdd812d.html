### 2.1 Architectural Proposal — A Vectorized Operator Runtime

The execution engine is a **pull-based (Volcano-style) or push-based (dataflow) tree of operators** that exchange **Arrow record batches**. My design principles:

1. **Batches are the unit of work.** Every operator consumes `RecordBatch` streams and produces `RecordBatch` streams. Row-at-a-time paths are forbidden on hot paths.
2. **Memory is reserved before it is allocated.** No operator allocates without a reservation from a shared `MemoryManager`. This is the invariant that makes spilling and OOM-avoidance tractable.
3. **Cancellation is cooperative and pervasive.** Every blocking call checks a cancellation token; a cancelled query releases reservations deterministically.
4. **Backpressure flows upstream.** A downstream operator that cannot accept input signals upstream to pause, rather than buffering unboundedly.

```
                    ┌─────────────────────────────────────────────┐
                    │              Query Coordinator               │
                    │   (plan → fragments → scheduling decisions)  │
                    └───────────────┬─────────────────────────────┘
                                    │  FragmentAssignment
              ┌─────────────────────┼─────────────────────┐
              ▼                     ▼                     ▼
     ┌────────────────┐   ┌────────────────┐   ┌────────────────┐
     │  Fragment 0    │   │  Fragment 1    │   │  Fragment N    │
     │  (scan+agg)    │   │  (scan+agg)    │   │  (scan+agg)    │
     └───────┬────────┘   └───────┬────────┘   └───────┬────────┘
             │  partial agg        │                    │
             └──────────┬──────────┴──────────┬─────────┘
                        ▼                     ▼
                 ┌─────────────────────────────────┐

                                 ▼
                        ┌─────────────────┐
                        │  Final Aggregate │
                        │  → Result stream │
                        └─────────────────┘
```

### 2.2 Core Components

**A. Operator interface (Java, idiomatic to a large engine codebase)**

```java
/**
 * A vectorized operator. Consumes and produces Arrow record batches.
 * Implementations MUST:
 *  - reserve memory before allocating
 *  - honor cancellation cooperatively
 *  - never block indefinitely without checking the cancellation token
 */
public interface Operator extends AutoCloseable {
    /** @return next batch, or null when exhausted. */
    RecordBatch next() throws IOException;

    /** Release all resources and reservations. Idempotent. */
    @Override void close();
}
```

**B. Memory management — reservation before allocation**

```java
public final class MemoryManager {
    private final long limit;
    private final AtomicLong reserved = new AtomicLong(0);

    /**
     * Reserve bytes or throw. Callers MUST release in a finally block.
     * This is the single choke point that makes spilling decisions possible.
     */
    public Reservation reserve(long bytes) {
        long now = reserved.addAndGet(bytes);
        if (now > limit) {
            reserved.addAndGet(-bytes);
            throw new OutOfMemoryReservationException(bytes, limit, now - bytes);
        }
        return new Reservation(this, bytes);
    }

    public static final class Reservation implements AutoCloseable {
        private final MemoryManager mgr;
        private final long bytes;
        private boolean closed = false;
        Reservation(MemoryManager mgr, long bytes) { this.mgr = mgr; this.bytes = bytes; }
        @Override public void close() {
            if (!closed) { mgr.reserved.addAndGet(-bytes); closed = true; }
        }
    }
}
```

**C. Spilling — partitioned hash-aggregate with merge-on-read**

When a hash-aggregate operator's reservation is denied, it spills the largest partition to disk and continues. On finalization, spilled partitions are read back and merged. This keeps memory bounded while preserving correctness.

**D. Scheduling & parallelism**

- **Fragment instances** are scheduled onto a work-stealing executor sized to available cores.
- **Exchange operators** partition by key with a bounded output queue; when the queue is full, upstream pauses (backpressure).
- **Skew handling**: hot partitions are detected via partition-size telemetry and can be split or broadcast.

**E. Caching**

- **Metadata cache**: Iceberg manifest lists, snapshot metadata, and Parquet footers cached with TTL + invalidation on snapshot change.
- **Split cache**: object-store range reads coalesced and cached by `(path, offset, length)`.
- **Result cache**: optional, keyed by normalized plan + snapshot ID, invalidated on table change.

### 2.3 Scalability Guarantees

| Property | Guarantee | Mechanism |
|---|---|---|
| Memory boundedness | Never exceed configured limit | Reservation-before-allocation + spill |
| Linear scan scaling | Throughput scales with fragment count | Partitioned splits, parallel scans |
| No unbounded buffering | Bounded queues everywhere | Backpressure propagation |
| Deterministic cancellation | Resources released within bounded time | Cooperative cancellation + try-with-resources |
| Skew resilience | Hot partitions don't stall the query | Partition splitting / broadcast |

- **CI/CD**: Every operator change ships with unit tests (batch-level correctness), integration tests (end-to-end query), and a benchmark gate (no >5% regression on TPC-H/TPC-DS subset).

## 3. Production-Ready Code / Architectural Proof

The following is an idiomatic, edge-case-hardened implementation of a **vectorized hash-aggregate operator with memory reservation and disk spilling** — the exact class of component this role builds. It is written in Java (the language of Dremio's engine) and uses Arrow-style batch semantics.

```java
package com.example.exec.operator;

import org.apache.arrow.vector.*;
import org.apache.arrow.vector.dictionary.DictionaryProvider;
import org.apache.arrow.vector.types.pojo.Schema;

import java.io.*;
import java.nio.channels.FileChannel;
import java.nio.file.*;
import java.util.*;
import java.util.concurrent.atomic.AtomicBoolean;

/**
 * Vectorized hash-aggregate operator.
 *
 * <p>Design invariants:
 * <ul>
 *   <li>All memory is reserved via {@link MemoryManager} before allocation.</li>
 *   <li>When a reservation is denied, the largest partition is spilled to disk
 *       and the operator continues — memory stays bounded.</li>
 *   <li>Cancellation is cooperative: {@link #next()} checks the token and
 *       releases reservations deterministically on close.</li>
 *   <li>Null keys are grouped into a dedicated partition (SQL semantics).</li>
 * </ul>
 *
 * <p>This is a simplified but faithful model of a production hash-aggregate:
 * it groups by a single key vector and computes COUNT/SUM over a value vector.
 */
public final class HashAggregateOperator implements Operator {

    private static final int PARTITIONS = 16;          // spill fan-out
    private static final long SPILL_THRESHOLD = 64L * 1024 * 1024; // 64 MiB

    private final Operator child;
    private final MemoryManager memoryManager;
    private final AtomicBoolean cancelled;
    private final int keyColumnIndex;
    private final int valueColumnIndex;

    // In-memory partitions: partitionId -> (key -> accumulator)
    private final List<Map<Key, Accumulator>> partitions = new ArrayList<>(PARTITIONS);
    private final List<Path> spillFiles = new ArrayList<>();

    private boolean inputExhausted = false;
    private boolean outputEmitted = false;

    public HashAggregateOperator(Operator child,
                                 MemoryManager memoryManager,
                                 AtomicBoolean cancelled,
                                 int keyColumnIndex,
                                 int valueColumnIndex) {
        this.child = Objects.requireNonNull(child);
        this.memoryManager = Objects.requireNonNull(memoryManager);
        this.cancelled = Objects.requireNonNull(cancelled);
        this.keyColumnIndex = keyColumnIndex;
        this.valueColumnIndex = valueColumnIndex;
        for (int i = 0; i < PARTITIONS; i++) {
            partitions.add(new HashMap<>());
        }
    }

    @Override
    public RecordBatch next() throws IOException {
        if (cancelled.get()) {
            throw new CancellationException("query cancelled");
        }
        if (!inputExhausted) {
            consumeInput();
        }
        if (outputEmitted) {
            return null;
        }
        outputEmitted = true;
        return emitResult();
    }

    /** Drain the child, aggregating into partitions, spilling when needed. */
    private void consumeInput() throws IOException {
        RecordBatch batch;
        while ((batch = child.next()) != null) {
            if (cancelled.get()) {
                throw new CancellationException("query cancelled during consume");
            }
            try {
                aggregateBatch(batch);
            } finally {
                batch.close(); // release child's buffers promptly
            }
            if (estimatedMemory() > SPILL_THRESHOLD) {
                spillLargestPartition();
            }
        }
        inputExhausted = true;
    }

    /** Aggregate one batch into the in-memory partitions. */
    private void aggregateBatch(RecordBatch batch) throws IOException {
        FieldVector keyVec = batch.getVector(keyColumnIndex);
        FieldVector valVec = batch.getVector(valueColumnIndex);
        int rows = batch.getRowCount();

        // Reserve memory proportional to the number of distinct keys we may add.
        // Worst case: every row is a new key.
        long reservationBytes = (long) rows * ESTIMATED_BYTES_PER_ENTRY;

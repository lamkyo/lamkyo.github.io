## 2. Deep Technical Solution Blueprint

### 2.1 Architectural thesis: cells, not one monolith

Regulatory licensing, data residency and blast radius all point the same way — **a control plane plus per-market data-plane cells**.

```
                    ┌──────────────────────── Control Plane (global) ───────────────────────┐
                    │  Identity/AuthN  ·  Config & Feature Flags  ·  Product Catalogue     │
                    │  Experimentation  ·  Analytics Lakehouse  ·  ML/LLM Model Registry   │
                    └───────────────┬──────────────────────┬──────────────┬─────────────────┘
                                    │                      │              │
               ┌────────────────────▼───┐   ┌──────────────▼──┐   ┌───────▼────────────┐
               │  MY cell (BNM scope)   │   │ ID cell (OJK)   │   │ PH cell (BSP)      │
               │  Ledger · Payments     │   │ Ledger · Pay    │   │ Ledger · Payments  │
               │  KYC · TM · Limits     │   │ …               │   │ …                  │
               │  Recon · Treasury      │   │                 │   │                    │
               └────────────────────────┘   └─────────────────┘   └────────────────────┘
```

Cross-cell flows (remittance corridors) are **explicit inter-cell sagas**, not shared databases. This keeps residency defensible, contains incidents to one market, and lets each cell adopt rail-specific behaviour without a global release train.

### 2.2 Ledger: append-only double-entry, derived balances

- **The journal is the source of truth.** Transactions contain ≥2 postings that sum to zero *per currency*. Balances are **derived**, never mutated in place. FX is modelled with explicit position/suspense accounts so no amount is ever silently "lost" in conversion rounding.
- **Balances are materialised, but as caches with checkpoints.** A `account_balances` row is an optimisation over journal replay, with a monthly/periodic checkpoint to bound recovery time. A nightly job re-derives every material account from the journal and compares digests.
- **Trial-balance digest published daily.** A hash of the full trial balance, emitted to an append-only audit log, cross-checked across replicas. Invariant violation = page, not ticket.
- **Money is integer minor units.** No floats anywhere in the money path, ever. Rounding rules are explicit, per-currency, and unit-tested at the boundary.
